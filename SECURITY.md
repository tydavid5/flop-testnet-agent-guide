# Security

## If you find a bug in FLOP itself

Tell FLOP privately. Email security@flop.finance, or use a private GitHub advisory on the FLOP repo. Never post a working exploit, a seed, a private key, or a keystore in public. FLOP says honest reports during testnet could earn a reward from the reserve, and using a bug to take money will lose you your share.

## If you find a mistake in this guide

Open an issue in this repo and link to the FLOP page that shows the right answer. Include the exact package version, the network, the command you ran, and the error with any keys removed. Never post keys, seeds, private host details, or API keys in an issue.

## What this repo will never ask for

This guide will never ask you for a seed phrase, a private key, a keystore password, or an API key in an issue, a form, or a chat. If something claiming to be this guide asks for one, stop. It is not us.

## Test keys used while writing this guide

Any test key made while checking the commands in this guide was deleted right after the check. No test address or test DID from those checks is published in this repo. Do not send funds to an address from a guide.
