# How to help

Thank you for reading this far. The best help is a correction with proof.

## How to report a mistake

Open an issue and link to the FLOP page that shows the right answer. Tell us:

1. What is wrong, in one sentence.
2. The FLOP page that shows the right answer, with its link.
3. The exact package version, the network, the command you ran, and the error, with any keys removed.

Never post a seed, a private key, a keystore, a password, or an API key in an issue. If you find a security bug in FLOP itself, see SECURITY.md and tell FLOP privately first.

## How to suggest a change

Keep it simple and human. Short sentences, plain words, and one change per issue or pull request. If you change a number, a version, or a command, say where you checked it and when. If you cannot check it live, say so in the issue, and do not present it as checked.

## What we do not accept

- A claim with no source.
- A version copied from an old guide.
- A testnet miner address or endpoint you cannot show is public and opted in.
- Any file that could hold a key, a wallet, or a secret. See .gitignore. If you are not sure, ask first.
